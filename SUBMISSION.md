# The Yard

Live: https://longtable.app.space

Repo: https://github.com/RDX-Rajat-Savdekar/longtable

Friends open one link and walk the same grass. There is no account. Each browser keeps a name, a color, and a small habit. The grass is a shared pixel picture. Three pictures: the Deepspace logo, a horse, and a dog. Walk with W A S D. The camera follows. Pick a color, click a square to paint it, click a painted square to clear it. The picture to copy sits in the corner, with a bar for how close the paint is, and a top-down map with a dot for each person. Cheat can jump the current picture to about 25, 50, 75, or 95 percent.

## Integrations

`openweathermap/current` paints the sky from the live weather in San Francisco. The app owner is billed, and the sky waits twenty minutes before it looks again.

Mail and a generated name were built, then taken out. Nobody has an address, because there is no account. The picture already has a name, so the yard does not ask a model to invent one.

## The tradeoff

One shared yard, not a set of private worlds. Anyone can clear a square, because an anonymous id changes every visit and cannot prove who painted a block. Progress on each picture is kept separately.
